# 🌈 Turtle Rainbow Spiral

A simple Python graphics project that uses the built-in `turtle` module and `colorsys` to create a colorful animated spiral pattern.

## ✨ Features

* Draws a colorful spiral using Turtle graphics
* Generates changing rainbow colors with HSV color conversion
* Uses geometric movements and circular arcs to create the pattern
* Runs with Python's built-in libraries

## 🛠️ Technologies

* Python
* Turtle
* Colorsys

## 🚀 How to Run

1. Make sure Python is installed.
2. Save the code as:

```bash
rainbow_spiral.py
```

3. Run:

```bash
python rainbow_spiral.py
```

A Turtle graphics window will open and draw the pattern automatically.

## 📌 How It Works

The program uses `colorsys.hsv_to_rgb()` to continuously change the drawing color while Turtle moves forward, rotates, and draws arcs. These repeated movements create the final rainbow spiral design.

## 📷 Output

The program generates a colorful geometric spiral on a black background.
